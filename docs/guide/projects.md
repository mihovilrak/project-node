# Projects

A project groups tasks, members and logged time. This page covers finding, creating and managing projects.

You see a project if you are a member or you created it. Administrators see every project.

## Browse projects

1. Select **Projects** in the app bar.
2. Sort with **Ascending** / **Descending**, and switch between list and grid view.
3. Use the filter panel to narrow the list. Active projects are shown by default.
4. Select a project to open it.

## Create a project

Requires **Create projects**.

1. On **Projects**, select **Create New Project**.
2. Enter a **Project Name** (required), and optionally a **Description**, **Start Date**, **Due Date**, **Status** and **Parent Project**.
3. Save. You become the project's creator and can see it straight away.

A parent must be a project you can see.

## Project details

The project page has five tabs:

| Tab | Contents |
| --- | --- |
| **Overview** | Description, dates, status, parent, creator, progress, estimated and spent time, and subprojects. |
| **Tasks** | The project's tasks and a **Create Task** button (needs **Create tasks**). |
| **Members** | Who is in the project. |
| **Time Log** | Time logged against the project's tasks, and a **Log Time** button (needs **Log time**). |
| **Gantt** | The project's tasks on a timeline. |

## Add a subproject

Requires **Create projects**.

1. Open the parent project's **Overview** tab.
2. Select **Add Subproject**.
3. Fill in the form as for a new project. **Parent Project** is already set.

## Edit or delete a project

Editing requires **Edit projects**. Deleting requires **Delete projects**.

1. Open the project.
2. Select **Edit** to change its fields, or **Delete** to remove it.

A deleted project gets the **Deleted** status. Its data stays in the database.

## Manage members

Requires **Edit projects**.

1. Open the project and go to the **Members** tab.
2. Select **Manage Members**.
3. Tick or untick users, then save.

When someone is added, the project's members, the new one included, get an **Added to Project** notification. Removing someone takes away their access to the project and its tasks, unless they created it.
