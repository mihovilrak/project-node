# Calendar

The calendar shows tasks on the days they run, so you can see what is due and when. This page covers opening it and switching views.

It shows tasks from the projects you can see whose start-to-due range overlaps the visible period.

## Open the calendar

1. Go to `/calendar` on your Project Node address, for example `https://pm.example.com/calendar`. There is no tab for it in the app bar.
2. The current month opens in **Month** view.

## Change the view

1. Select **Day**, **Week** or **Month** at the top right.
2. Use the arrows to move one month back or forward, whatever the view.
3. Select the **Today** icon to jump back to the current date.

## Open a task

1. Select a task chip in any view.
2. The task page opens. See [Tasks](/guide/tasks).

Month view shows task names only. Day and Week views also show priority and status.

For hours logged per day, use the project time calendar described in [Time tracking](/guide/time-tracking#review-time).
