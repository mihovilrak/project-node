# Calendar

The calendar shows tasks on the days they run, so you can see what is due and when. This page covers opening it, switching views and how tasks are placed.

It shows tasks from the projects you can see whose start-to-due range overlaps the visible period, and the time you have logged yourself.

## Open the calendar

1. Select **Calendar** in the app bar.
2. The current month opens in **Month** view.

## Change the view

1. Select **Day**, **Week** or **Month** at the top right.
2. Use the arrows to move one month back or forward, whatever the view.
3. Select the **Today** icon to jump back to the current date.
4. In **Week** view, select a day's heading to open that day in **Day** view.

## How tasks are placed

- A task appears on every day from its start date to its due date.
- In **Day** and **Week** views, a label says whether the task **Starts**, is **Due** or **Ended** that day.
- Task dates usually have no time of day. Such tasks are listed under **All day** in **Day** view.
- A task whose start has a time of day is shown in that hour's slot, on its start day only. On the following days it is listed under **All day**.

## Open a task

1. Select a task chip in any view.
2. The task page opens. See [Tasks](/guide/tasks).

Month view shows task names only, up to three per day. Day and Week views also show priority and status.

## Your logged time

Each day shows **Time logged** with the hours you logged on it. **Day** and **Week** views also list the entries. Select one to open its task.

For a whole project's hours per day, use the project time calendar described in [Time tracking](/guide/time-tracking#review-time).
